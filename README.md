# Broker Portal

This repository contains a minimal Express-based broker portal skeleton. Brokers log in with a code, access insurance application forms, and new brokers are directed to a registration form.

## Running the project

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Run tests:
   ```bash
   npm test
   ```

Replace the placeholder JotForm URLs in `public/dashboard.html` and `public/new-broker.html` with your own form links.
